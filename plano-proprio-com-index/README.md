# Plano Próprio System — versão HTML

## Abrir no computador

Extraia todos os arquivos do ZIP para uma pasta. Abra `index.html` no navegador com dois cliques. Mantenha as pastas `assets`, `images` e `visuals` junto ao `index.html`.

Esta versão não exige Node.js, npm ou servidor local. JavaScript deve estar habilitado no navegador.

## GitHub Pages

Envie todo o conteúdo deste ZIP para a raiz do repositório, incluindo `index.html`, `assets`, `images`, `visuals`, `favicon.svg` e `.nojekyll`.
Nas configurações de Pages do repositório, selecione a publicação a partir da branch desejada e da pasta raiz.

## Conteúdo

Versão local atual da página, com imagens, fontes, simulador, perguntas expansíveis, scroll suave, animações e timeline do System. As seis etapas Criar → Crescer mantêm o layout original, conforme solicitado.

Esta é a versão pronta para abrir e hospedar. O ZIP de código-fonte entregue anteriormente continua disponível para editar os componentes React.
